# ผลตรวจระบบออนไลน์ รุ่น online-8

ตรวจวันที่ 10 พฤศจิกายน 2026 ด้วยบัญชีและข้อมูลทดสอบแยก ไม่แก้ข้อมูลผู้เล่นจริง
ผลนี้ยืนยันเฉพาะกรณีที่ระบุ ไม่ใช่การรับรองว่าทุกปุ่ม ทุกสถานการณ์ และทุกจำนวนผู้เล่นผ่านทั้งหมด

## แก้ไขในรอบนี้

- ซื้ออาวุธเริ่มต้น ยศ ขายขยะ เรียงกระเป๋า สกรอลกลับเมือง สัญญาทหารรับจ้าง และพรีเซ็ต ส่งคำสั่งไป authority
- จำนวนแลกเพชร/ตั๋วใช้ค่าที่กรอกจริง หน้าต่างตีบวกและสุ่มค่ารอผลเซิร์ฟเวอร์
- แพ็กแฟชั่นเปิด/ขาย/ทิ้งและขายหลายชิ้นตรวจเจ้าของ ของล็อก และของที่สวมอยู่
- คืนหน้าต่างยืนยันขายทั้งหมดเดิม และรอออโต้สวมสำเร็จก่อนเลือกของที่เหลือไปขาย
- ออโต้สวมหลังรับไอเทมทำงานในบริบทเจ้าของ ไม่ไปเปลี่ยนของผู้เล่นแรกในแมพ
- กิลด์ใช้สมาชิก/คำขอ/อันดับจากข้อมูลจริง ไม่สร้างสมาชิกจำลองตอนกดสร้างกิลด์
- พาหนะ ความเร็วขี่ สัตว์เลี้ยงของตัวเองและเพื่อน และระยะเก็บของ ใช้ข้อมูลร่วมจากเซิร์ฟเวอร์
- ทหารรับจ้างในดันเจี้ยน/PvP ใช้สัญญาและทองเจ้าของ AI ทำงานบนเซิร์ฟเวอร์ มีชื่อระบุว่าเป็นทหารรับจ้าง และกู้คืนหลัง checkpoint ได้
- ลานบอสโลกแยกตัวเลือกมี/ไม่มี NPC ตามปุ่มเดิม NPC ปาตี้ติดป้าย NPC และถูกซิงก์ให้ทุกคนในห้องเห็น
- กิลด์วอร์จับคู่กิลด์ที่เลือก แยก Ranked/Friendly/Wager; Friendly ไม่แจกเงิน/อันดับแข่งขัน เงินเดิมพันเก็บและชำระจากกองเงินจริง คืนเมื่อออกก่อนจบหรือเปลี่ยนโลกหลัง restart
- รางวัลศึกชิงบอสแจกเฉพาะผู้เล่นจริงในทีมชนะ ไอเทมแต่ละคนมี ID ต่างกัน
- GM เพิ่ม named item, mercenary rank, bot power, boss interval, import, guild rating และ reward configuration ผ่านเซิร์ฟเวอร์; รางวัลชนะกิลด์ใช้กติกาโบนัสเดิมและบันทึก EXP กิลด์ส่วนกลาง
- หยุดคำนวณ fingerprint ทุก simulation tick เมื่อไม่มีข้อมูลเปลี่ยน
- Google ยังไม่เปิดตามที่เจ้าของเลือก ใช้บัญชีเกม/ผู้เยี่ยมชม ปุ่มเดิมแสดงสถานะชัดเจน

## ขอบเขตที่ยังไม่ควรเรียกว่าเสร็จทุกระบบ

- เครื่องมือ GM สำหรับโลกจำลองเดิม เช่น เพิ่ม/จำลองกิลด์บอท จบซีซันจำลอง เชิญ/ปรับเลเวลสมาชิกบอท และเติมของให้ผู้เล่นจำลอง ยังปิดในโลกออนไลน์ ไม่ได้แอบรันแก้เซฟในเบราว์เซอร์ การจัดการสมาชิกจริงใช้หน้าสมาชิกออนไลน์
- Google ไม่มี Firebase/OAuth และยังไม่เปิดตามที่เจ้าของเลือก
- ยังไม่มีการทดสอบเล่นยาวทุกแมพ ทุกสกิลผสม และโหลดจำนวนมากบน Cloudflare จริง
- itch.io ของเจ้าของจะเปลี่ยนเป็นรุ่นนี้หลังเจ้าของอัปโหลด ZIP ใหม่เท่านั้น การ deploy Worker ไม่เปลี่ยนไฟล์ itch.io อัตโนมัติ

ต้องใช้รายงานนี้ประกอบการประเมิน ห้ามสรุปเพียงว่า “74 tests ผ่าน = ทั้งเกมเสร็จทั้งหมด”
